# 🏭 Industry — Industrial Solutions Website

A modern and responsive industrial website built with HTML, CSS, and Font Awesome. This project showcases industrial services, engineering solutions, construction projects, and maintenance services through a clean and professional design.

## 🔗 Live Demo
[View Industry Website](https://elyardev.github.io/Industry/)

## ✨ Features
- 🏗️ Modern industrial website design
- 📱 Responsive layout for different screen sizes
- 🧭 Navigation bar with multiple sections
- ⚙️ Industrial services and market sectors
- 🖼️ Latest projects gallery
- 📊 Statistics and achievements section
- 📝 Request a Quote form
- 📩 Newsletter subscription form
- 🎨 Font Awesome icons

## 🛠️ Built With
- HTML5
- CSS4
- Responsive Web Design
- Font Awesome

## 🚀 Getting Started
1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
